Publicar no site

Atualiza o site público elizcarvalho.github.io/odin-cockpit com tudo que está aqui (exames, remédios, vacinas e fotos). Os dados pessoais são removidos na hora de publicar.

  1. Clique em Exportar para o site. O arquivo odin-export-AAAA-MM-DD.json vai pra pasta Downloads.
  2. No terminal, entre na pasta do repositório: cd ~/Documents/GitHub/odin-cockpit
  3. Pra conferir antes (opcional): npm run publicar e depois npm run ver, que abre em localhost:4173.
  4. Pra publicar: npm run publicar -- --push. O site atualiza em 1 a 2 minutos.

Se o script parar avisando que sobrou um nome, inclua esse nome em config/anonimizacao.json e rode de novo. Ou só me peça pra publicar.
